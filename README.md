# Zenty Finance - AI-Powered Personal Finance Assistant

An intelligent personal finance management system with AI chatbot, budget tracking, stock monitoring, and financial insights.

## Features
- 💬 AI Financial Assistant powered by ML models
- 📊 Transaction Tracking
- 💰 Budget Management
- 🎯 Savings Goals
- 📈 Stock Portfolio Tracking with live data
- 📉 Analytics & Insights

## Tech Stack
- **Backend:** FastAPI + Python 3.11
- **ML/AI:** PyTorch, Transformers, spaCy
- **Database:** SQLAlchemy
- **Stock Data:** yfinance

## API Endpoints
- `/health` - Health check
- `/docs` - Interactive API documentation
- `/api/chat` - AI assistant endpoint
- `/api/transactions` - Transaction management
- `/api/budgets` - Budget tracking
- `/api/stocks` - Stock portfolio
